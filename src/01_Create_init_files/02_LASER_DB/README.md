# LASER DB Processing

## Overview

The `src/01_Create_init_files/02_LASER_DB` directory contains Jupyter notebooks and helper scripts to process the **LASER** database (Library of Advanced Semiconductor Equipment Research). The workflow:

- Parses locally downloaded LASER year index HTML pages to discover `Record*.txt` entries.
- Downloads and loads the **Product Ontology**.
- Extracts product **tags** per record and parses bibliographic fields from LASER `Record*.txt` pages.
- Normalizes and corrects DOIs.
- Queries PubMed to retrieve article metadata.
- Curates irreconcilable cases and writes a final, cleaned article table for downstream use.

## Workflow Overview

### 1. Extract LASER Categories & Tags
**Notebook**: `01_Extract_LASER_categories_and_tags.ipynb`

**Goal**
Discover LASER `Record*.txt` references from local year HTML pages, download the Product Ontology, extract **product tags** per record, and save consolidated tags.

**Key Steps**
- Setup: import project helpers (`check_save_file`, `get_files_dir`) and `get_tags` from `parse_LASER`.
- Paths: create/use `INPUT_DIR/LASER` and `INPUT_DIR/LASER/LASER_webfiles`.
- Parse year HTMLs (`2014.html`, `2015.html`, latin encoding) to extract `Record*.txt` via regex `r"Record.{1,30}\.txt"` and deduplicate per year.
- Download **LASER_product_ontology.txt** (if missing) and load as tab-separated table.
- Call `get_tags(papers_sets, database_url)` to iterate LASER records and collect tag names.
- Save **`LASER_TAGS.json`** under `INPUT_DIR/LASER`.

**Inputs**
- `../../files/LASER/LASER_webfiles/2014.html`
- `../../files/LASER/LASER_webfiles/2015.html`
- Remote ontology and database store URLs

**Outputs**
- `LASER_product_ontology.txt`
- `LASER_TAGS.json`

### 2. Extract LASER Information
**Notebook**: `02_Extract_laser_information.ipynb`

**Goal**
Parse LASER `Record*.txt` pages to extract **primary product tags** and **bibliographic metadata**, normalize and curate DOIs, query PubMed to retrieve article info, and produce a **final curated** article table.

**Key Steps**
1. **Setup & Inputs**
   - Extend `sys.path` to include `../../02_Classify_articles` and project root.
   - Use: `get_files_dir`, `check_save_file`; functions from `extract_NCBI`; and `create_primary_tags`, `get_LASER_html`, `read_LASER_html` from `parse_LASER`.
   - Load `LASER_TAGS.json` and reduce to unique tag set.
   - Read year HTML pages (`2014.html`, `2015.html`) and build `papers_sets`.

2. **LASER Record Parsing**
   - For each year and record ID:
     - Initialize per-record fields with `create_primary_tags(papers_def, record, full_tags)`.
     - Fetch LASER record HTML via `get_LASER_html(year_url, record)`.
     - Parse fields with `read_LASER_html(html, papers_def, record)` (including nested mutant structures).
   - Assemble `parsed_data[year]` as DataFrames; wrap into `datos` and save **`parsed_LASER_DB.json`**.

3. **DOI Normalization & Manual Curation**
   - Normalize DOI strings (strip `doi:`, `doi/`, `doi.org/`, quotes, plus signs).
   - Apply a curated mapping of known malformed DOIs → corrected DOIs.
   - Build `updated_dois = (DOI, Title)` unique pairs; patch specific edge cases.

4. **PubMed Integration**
   - For each valid DOI: `search_entrez(doi)` → take first PubMed ID if present.
   - Batch-download article metadata with `collect_relevant_info(articles_ids, DB_articles_file, batches_len=200)`.
   - Load `LASER_articles.csv` (TSV), drop duplicates, and compare PubMed DOIs/titles vs LASER DOIs to flag mismatches.

5. **Manual Abstract Recovery & Final Curation**
   - Use `doi_dict` (DOI → abstract) to fix unmapped cases; assemble `add_info` with fields: `PM_ID`, `PMC_ID`, `Type`, `Author`, `Journal`, `Year`, etc.
   - Remove mismatched PubMed IDs from `laser_articles` when a curated entry is provided; concatenate with `add_info` → `curated_laser`.
   - Save **`LASER_articles_curated.csv`** (TSV) under `INPUT_DIR/LASER`.

**Inputs**
- `../../files/LASER/LASER_TAGS.json`
- `../../files/LASER/LASER_webfiles/2014.html`
- `../../files/LASER/LASER_webfiles/2015.html`
- Remote LASER record base URL (`.../database_store/`)

**Outputs**
- `../../files/LASER/parsed_LASER_DB.json`
- `../../files/LASER/LASER_articles.csv` (TSV)
- `../../files/LASER/LASER_articles_curated.csv` (TSV)

## Helper Functions (`parse_LASER.py`)

- **`get_LASER_html(url, record)`**  
  Fetches `Record<id>.txt` with a permissive SSL context and simple retry loop.

- **`get_tags(papers_sets, database_url)`**  
  Iterates all records referenced in the year HTMLs, streams each record, collects the left-hand-side tag names, and returns:
  ```json
  {
    "Counts": <int>,
    "Full_list": [<all tag names>],
    "Set": [<unique tag names>]
  }
  ```

- **`create_primary_tags(papers, record, full_tags)`**  
  Initializes all non-`Mutant*` tag fields to `None` for a given record.

- **`read_LASER_html(html, papers, record)`**  
  Parses `key=value` lines, creating nested structures for `Mutant*` tags (via `extract_mutants`). Handles special case `_Gonzalez_BetaOxidation` with implicit mutant count.

## Parameters
- Years parsed: `2014`, `2015`
- Record regex: `r"Record.{1,30}\.txt"`
- PubMed batch size: `200`
- HTML encoding (year pages): `latin`
- SSL verification: disabled (`check_hostname=False`, `verify_mode=CERT_NONE`)
